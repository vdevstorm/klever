Official website

VeyPlay

Watch and organize your YouTube content in one convenient app. VeyPlay is a media application for discovering, watching and organizing YouTube content using the official YouTube player. With the user's consent through Google OAuth, VeyPlay can show subscriptions, playlists and liked videos. The Free version may show ads, while VeyPlay Pro is an optional subscription.

VeyPlay là ứng dụng xem và quản lý nội dung YouTube bằng official YouTube player. Người dùng có thể đăng nhập bằng YouTube OAuth để xem nội dung cá nhân, quản lý subscriptions, playlists và video đã thích.

How VeyPlay uses Google user data

VeyPlay requests Google/YouTube access only after the user chooses to sign in. We use the authorized data to authenticate the user and display the user's YouTube subscriptions, playlists and liked videos inside VeyPlay. This data is used to provide the requested app features, is not sold, and is not used for unrelated advertising. VeyPlay does not collect or store the user's Google password; the user can revoke access at any time.

  • Purpose: sign in and show the user's YouTube account content.
  • Data used: basic account identity and the YouTube resources needed for subscriptions, playlists and liked videos.
  • User control: access is optional and can be revoked from the user's Google Account; see our Privacy Policy.
